Cấu hình Firebase Realtime Database

Đồng bộ tồn kho lên Firebase để tất cả mọi người mở file này đều tự thấy dữ liệu mới nhất. Dữ liệu ghi vào 3 nhánh: tonkho_latest (bản mới nhất, ai mở trang cũng tự tải), tonkho_snapshots/{ngày} (lưu lịch sử) và tonkho_meta (thời gian cập nhật). Nhập ở đây chỉ áp dụng cho phiên làm việc hiện tại — để mọi người không phải tự nhập, hãy dán Database URL này vào hằng số FIREBASE_CONFIG ở đầu mã nguồn rồi lưu/host lại file.

Chưa đồng bộ lần nào.

Đồng bộ Firebase (thời gian thực)

Kết nối với Firebase Realtime Database để nhiều người dùng cùng thấy thay đổi của nhau ngay lập tức (không cần chờ đồng bộ theo chu kỳ). Miễn phí cho quy mô nội bộ như dự án này.

Bước 1 — Tạo project Firebase (chỉ cần làm 1 lần)

1. Vào console.firebase.google.com → Tạo project mới (miễn phí).
2. Trong menu trái, vào Build → Realtime Database → Tạo database (chọn khu vực gần Việt Nam, ví dụ Singapore/asia-southeast1) → chọn chế độ bắt đầu ở "Test mode" (sẽ khóa lại ở bước dưới).
3. Vào Build → Authentication → Sign-in method → bật Anonymous (giúp chỉ ai mở đúng app này mới đọc/ghi được dữ liệu, chặn người lạ trên mạng).
4. Vào Realtime Database → tab Rules, dán quy tắc bảo mật bên dưới rồi Publish.
5. Vào ⚙️ Project settings → General, cuộn xuống mục "Your apps" → bấm biểu tượng Web </> để tạo 1 Web App → sao chép đoạn firebaseConfig được cấp.

Bước 2 — Dán cấu hình Firebase

Dán nguyên đoạn const firebaseConfig = { ... } (hoặc chỉ phần { ... }) mà Firebase đã cấp cho bạn ở bước 1.5.

Chưa kết nối Firebase — dữ liệu chỉ đang lưu trên trình duyệt này.
